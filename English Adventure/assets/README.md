# Assets (`assets/`)

Chỉ sử dụng tài nguyên có bản quyền hợp pháp / tự sản xuất / CC0 đã kiểm chứng:
- `characters/`: Explorer Boy, Explorer Girl, Buddy, Professor Owl, NPCs, Echo Guardian.
- `environments/`: Tài nguyên bản đồ 2.5D/3D Alphabet Island.
- `animations/`: SpriteFrames / AnimationLibraries chuẩn hóa 6 states.
- `ui/`, `icons/`: UI theme, nút bấm, huy hiệu, Magic Crystals.
- `audio/`: BGM, SFX, Voices (`en-US/`, `en-GB/`, `vi-VN/`).
- `fonts/`: Nunito/Quicksand (UI tiếng Việt) và Andika/Noto Sans (chữ học & IPA).
- `learning/`: Hình ảnh minh họa từ vựng & câu (`.webp`).
