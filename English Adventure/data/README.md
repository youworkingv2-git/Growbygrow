# Learning Data Packs (`data/`)

Kho dữ liệu học tập độc lập hoàn toàn với code game (xem chi tiết tại `docs/LEARNING_CONTENT_SPEC.md`):
- `schemas/`: JSON Schemas dùng để validate tự động trước khi đóng gói.
- `alphabet/`: 26 chữ cái tách biệt `letter_name` và `letter_sound`.
- `phonics/`: Bài học ngữ âm & quy tắc ghép vần CVC.
- `vocabulary/`: Danh sách từ vựng chuẩn hóa (`word_001`..), tái sử dụng cho mọi mini-game.
- `grammar/`: Các mẫu câu và slot cấu trúc câu.
- `listening/`, `reading/`: Dữ liệu bài nghe & đọc hiểu chuyên biệt.
- `quests/`: Định nghĩa 18 Quests trên World 1 – Alphabet Island.
