# Localization (`localization/`)

- `vi/`: File dịch giao diện tiếng Việt (`ui_vi.csv` / `.po`) – ngôn ngữ hướng dẫn mặc định cho trẻ em Việt Nam.
- `en/`: File dịch giao diện tiếng Anh (`ui_en.csv` / `.po`).

Lưu ý: Dữ liệu bài học tiếng Anh (từ vựng, phiên âm, ví dụ) nằm ở `data/`, không trộn vào file dịch UI.
