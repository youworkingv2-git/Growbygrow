- `authentication/`: Login (`#2`), Character Selection (`#3`), Initial Assessment (`#4`)

- `world_map/`: World Map (`#6`), World Detail (`#7`)
- `adventure/`: World 1 Alphabet Island 2.5D/3D scene & Adventure HUD (`#10`)
- `quests/`: Quest Selection (`#8`), Quest Introduction (`#9`)
- `mini_games/`: 5 MVP mini-games + Learning Feedback (`#11`)
- `rewards/`: Reward Screen (`#12`), Inventory (`#13`), Achievement (`#14`)
- `profile/`: Player Profile (`#15`)
