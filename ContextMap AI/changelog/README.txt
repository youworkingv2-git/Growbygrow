# Changelog — quy ước ghi thay đổi

Mỗi lần chỉnh sửa dự án ContextMap AI, tạo **một file text riêng** trong thư mục này.

## Đặt tên file

```
YYYY-MM-DD_HHmm_<mo-ta-ngan>.txt
```

Ví dụ: `2026-07-22_1844_them-huong-dan-su-dung.txt`

## Nội dung tối thiểu trong mỗi file

- Thời gian
- Tóm tắt thay đổi (1–2 câu)
- Chi tiết: file nào thêm / sửa / xóa
- Lý do (nếu có yêu cầu từ người dùng)

## Lưu ý

- Mỗi lần thay đổi = 1 file mới (không ghi đè file cũ).
- Viết bằng tiếng Việt, rõ ràng, dễ đọc lại sau này.
